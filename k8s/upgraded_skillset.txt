## 🔄 Current Workflow I Follow

1. Start Minikube
2. Use Minikube Docker environment:

   * eval $(minikube docker-env)
3. Build images:

   * docker build -t drift-backend:1.0 ./backend
   * docker build -t drift-frontend:1.0 ./frontend
4. Verify images:

   * minikube image ls
5. Apply Kubernetes YAML files:

   * kubectl apply -f k8s/
6. Verify:

   * kubectl get pods
   * kubectl get svc
7. Access application:

   * minikube service frontend
